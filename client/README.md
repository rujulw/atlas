# Atlas Client

React + Vite + TypeScript frontend for Atlas.

Current client surface:

- `/`: branded landing page describing the Atlas platform direction
- `/docs`: placeholder docs route
- `/app`: protected app shell scaffold for future authenticated flows

Key frontend pieces:

- Tailwind CSS v4 styling
- React Router route structure
- Framer Motion viewport/entrance animation on the landing page
- shared `Navbar`, `LiquidGlass`, and `Aurora` presentation components

## Local development

```bash
cd client
npm install
npm run dev
```
